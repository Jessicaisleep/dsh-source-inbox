# 素材收件箱

把**你自己各账号**的资料汇聚进一个本地知识库的统一工作栏，创作时不用再手动复制粘贴给模型。

## 当前状态 —— Phase 1（底座 + 投放区观察适配器）+ Phase 2（分步引导 + 自己读页面 + 凭据输入框）

Phase 0 底座已交付并验收；本版在此基础上接通第一个自动源：

- **统一工作栏**（侧边栏）：总览、导入向导、数据源阶梯状态、可浏览记录列表与有长度上限的 Markdown / 文字影子预览。
- **双轨归档**（规划 §4.2）：文字资料 *materialized* 落盘；大素材只存 *reference* 指针 + 一个小文字影子，保证仍能检索到。
- **统一 schema**：每条记录含来源、阶梯、标题、时间戳、MIME、存储轨、路径、标签、校验和、AI 对话字段。
- **导入向导**：接收官方导出 / 分享 / 剪藏产物的绝对路径。按魔数嗅探（纠正错误扩展名）、MIME 分类、校验和去重、ZIP 展开、归一化落盘。
- **模型工具**：`inbox_status`、`inbox_sources`、`inbox_list`、`inbox_read`、`inbox_import`、`inbox_adapters`、`inbox_watch`、`inbox_scan`、`inbox_browser`、`inbox_open_login`、`inbox_read_page`、`inbox_credentials`（只读、打码）、`inbox_remove`。
- **数据源清单与引导**：28 个规划数据源按 A–G 分组，映射到四级接入阶梯（L0 官方 API → L1 受限官方 API → L2 网页登录态 → L3 导出/分享），每条附官方导出/分享做法。
- **★ 每个数据源的官方入口按钮**（2026-11 新增）：清单里 21/28 条带一键按钮，点开由系统浏览器打开该平台**官方**页面 —— 官方给接口的（飞书/腾讯文档 MCP Token、Notion 授权、百度网盘开放平台、夸克/知乎/小红书等）直接到登录或控制台；只走网页登录态的（公众号、抖音/小红书创作者中心、视频号助手）直接到登录页；官方只给导出/分享的（语雀、微信读书、flomo、DeepSeek/元宝/豆包导出）直接到导出入口。剩下 7 条是本地通道（Obsidian 库、书签、日历）或必须在手机/客户端内完成的官方备份（个人微信/QQ），清单里写明原因而不是给一个点不动的按钮。按钮只做跳转，**不嵌页面、不碰凭据**；URL 白名单只接受 https，走宿主 `window.open → shell.openExternal`。
- **★ Phase 1 自动源适配器**：「投放区观察器」监视一个本地落地目录，新文件出现即自动走导入向导 / 双轨归档 / 合规闸门（魔数纠正、校验和去重、聊天数据库拦截）。它是所有 *file-producing* 源（Wandao / 微信合并转发 ZIP / DeepSeek 导出 / 元宝转文档）的统一底座。工作栏里可配置观察目录、轮询间隔、来源 id、标签，并可「立即扫描一次」。
- **★ 登录之后的分步引导**（Phase 2）：光给一个按钮等于把人送到门口就断线。现在 **28/28** 条都带步骤（共 86 步），每步写清「点哪里 → 拿到什么 → 填到哪里」。飞书是完整 5 步（开发者后台建自建应用 → 权限管理勾 docx/drive/wiki/bitable 只读并批量开通 → 复制 App ID/Secret 存 `_secrets\feishu.json` → 版本管理与发布**并发版过审**（最容易漏）→ 换成 user_access_token）；腾讯文档 4 步（含 `400006` = Token 错/过期、`400007` = 非超级会员、Header 必须是 `Authorization: <token>` 而非 Bearer）；邮箱 4 步（明确「填授权码不是登录密码」）。
- **★ 让插件自己读（不再手动复制）**（Phase 2）：**7 个源 / 11 个页面**可以直接读 —— 夸克网盘、Cubox、小宇宙/喜马拉雅、Figma、抖音/小红书/视频号/即梦的创作者后台、知乎收藏、公众号。点「⟳ 让插件自己读」后，插件启动**自己独占的** Chromium 打开该页，登录态过期就先把这个页面在插件窗口里亮出来让你扫码，登录完再点一次即可，读到内容自动归档成一条 Markdown 记录（带来源、URL、抓取时间与「未经人工校对」标注）。
  - **为什么是独立浏览器**：日常 Chrome/Edge 没开调试端口，插件附加不上；即使能附加，也会读到你在所有站点的 cookie。所以用插件私有 profile，把可见范围限制死。
  - **白名单闸门**：只有源注册表里声明过的 https 页面可读；空白名单 = 什么都不允许；`quark.cn.evil.com` 这类后缀伪造、URL 内嵌账号密码、重定向到别域都会被拒。
  - **登录墙不假装成功**：登录态过期时页面仍返回 200 和几百字「扫码登录」，插件会判定为 `loginRequired`、**不归档**、并帮你打开该页面，而不是把登录页当内容塞进知识库。判据是登录框专属 UI 串（`扫码登录`/`请先登录`/`Log in to continue` …）和 URL 里的 `/login`、`/signin`、`passport.`，**不是页面长度** —— 真实登出的抖音页有 1127 字，靠长度判断会把登录页当正文存下来。
- **★ 凭据不再是「自己去建文件」**（Phase 2.3）：以前引导写「拿到 App ID / App Secret → 填到 `_secrets\feishu.json`」，等于让用户自己建文件、猜 JSON 键名、手敲格式 —— 写错了没有任何报错，适配器只是静默读到空。现在 **8 个需要凭据的源（飞书 / 腾讯文档 / Notion / 百度网盘 / 微信读书 / Cubox / Figma / 邮箱，共 14 个字段）在那一行里直接给输入框**，密码字段是 `password` 类型，粘贴后点「保存到本地」即可。
  - **谁写文件**：插件写，不是用户写。默认落盘到 `$DSH_HOME/_secrets/<file>.json`（未设 `DSH_HOME` 时为 `~/.dsh/_secrets`；也可用 `config.secretsDir` / `DSH_SECRETS_DIR` 指定别处，相对路径会被拒绝而不是落到不可预期的 cwd），tmp + rename 原子写，POSIX 上 `0600`，并带 `_meta` 记来源与保存时间。文件名由注册表声明，只接受裸文件名（`../x`、子目录、非 `.json` 一律报错）。
  - **只回显打码预览**：界面和任何接口都只返回 `saved` 与 `cli_****（12 位）` 这种预览，**明文不出现在 API 响应、日志、工具返回里**。因此也**故意没有**「用工具保存凭据」的 tool —— 密钥一旦作为参数传进来就会留在对话记录里，保存只在面板输入框里做。
  - **输入框是 uncontrolled 的**：值只活在 DOM 里直到点保存，不进组件 state，避免顺手被日志或调试输出带走。空着保存 = 保留已存值，所以「这次先贴 App Secret、下次再补 App ID」也能用。
  - **拒绝的东西**：未声明字段（报 `unknown credential field`）、超 4096 字符、含不可见控制字符、全空保存。被拒的保存不改动磁盘上任何内容。
- **★ 记错了能撤回**（Phase 2）：记录预览里有「删除这条记录」，模型侧是 `inbox_remove` / `POST /api/remove`。删一条会重写 `manifest.jsonl` 并删掉它**独占**的文件；如果旧数据里两条记录还共用一个文件，则保留文件不动，避免把另一条的正文删空。

**官方 MCP / API 源**（腾讯文档 / 飞书 / 夸克 / Notion 等）需要用户先给一次账号授权，**当前未接通**，注册表里诚实标为 `needs-auth`，不会假装它能跑。配置存 `<dataDir>/adapters.json`，不改写 profile 的用户配置层。

## 合规红线

个人微信 / QQ 聊天记录只走用户自己产出的**官方**备份 / 「合并转发」/ 分享导出文件，再当作普通文件导入；插件绝不读取、绝不解密本地聊天数据库。（chatlog 项目 2025-10-20 收到官方函件后删库；腾讯 2026-01-22 向 GitHub 投诉要求下架逆向本地数据库密钥的项目。）

## 怎么用

1. 在侧边栏打开「素材收件箱」。
2. 在来源平台产出官方导出文件（做法见「数据源清单」卡片里每条的引导）。要先去登录 / 取 Token 的，直接点那条的 **↗ 按钮**，系统浏览器会打开该平台的官方页面；按下面的 1/2/3 步骤一步步做（每步都写了「拿到什么、填到哪里」）。**拿到 App ID / Secret / Token / 授权码之后，直接粘到这一行的输入框里点「保存到本地」** —— 不用自己建文件、不用按 JSON 格式手写，插件负责落盘，界面上只显示 `cli_****（12 位）` 这样的打码预览。
3. **能直接读的就别导**：带「⟳ 让插件自己读」的源（夸克 / Cubox / 小宇宙 / Figma / 抖音 / 小红书 / 视频号 / 即梦 / 知乎 / 公众号），点一下 —— 第一次会弹出插件自己的浏览器窗口让你扫码登录，登录完再点一次，列表就直接变成归档记录。
4. 需要文件的，把**绝对路径**粘进导入向导，点「导入」。记录出现在列表里，点任意一条预览归一化文本。
5. 让模型调用 `inbox_*` 工具，或直接在面板里浏览。

## 数据位置

默认 `<DSH_HOME>/data/dsh-source-inbox/`（例如 `D:\Program Files (x86)\DSH_Data\data\dsh-source-inbox`）。可用 `config.dataDir` 或环境变量 `DSH_SOURCE_INBOX_DIR` 覆盖。追加式索引为 `manifest.jsonl`，子目录：`_raw/`、`materialized/`、`reference/`、`assets/`、`dropzone/`（默认观察目录）、`browser-profile/`（受控浏览器私有 profile，登录态只留在里面），以及 `adapters.json`（观察器配置）。观察目录不能落在归档目录内（防反馈环）。

大素材文件**不会**被复制进存储区。请把官方导出原件留在原处；记录只保存指针与一个文字影子占位，待后续 transcript / OCR / AI 摘要适配器填充。
